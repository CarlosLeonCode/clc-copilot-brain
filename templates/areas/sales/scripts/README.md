# Scripts

This folder holds your sales scripts: the exact words to say in each conversation. One file per script set (for example one industry), plus a page that `clc-brain view` generates beside each file.

You don't write them by hand. Ask your assistant: "Make me a script for X". It asks a few questions, shows a preview, and saves only after you say yes.

File names are in English (for example `acme-retail.md`), even in a Spanish brain. This note is not a script, so it never shows up on your sales page.
